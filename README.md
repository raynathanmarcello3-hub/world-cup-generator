#  World Cup Simulator

Simulate the entire FIFA World Cup tournament 
and find out who becomes the champion!


## How to Run

1. Download or clone this project
2. Open `index.html` in your browser
3. Click "Start World Cup"
4. See who wins!

## Tech Used

- HTML
- CSS  
- JavaScript
